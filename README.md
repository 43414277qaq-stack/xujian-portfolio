# 徐剑 · AI 视觉作品集

用 AI 创作漫剧、短剧、海报、角色与场景的个人作品集网站。

## 技术栈

纯静态单页应用，零构建、零依赖：

- HTML / CSS / JavaScript
- Coverflow 循环卡片轮播（自由拖拽 + 惯性甩动）
- 视频灯箱（自定义进度条：点击跳转 / 长按拖拽 / 松手续播）
- 背景粒子 / 光晕 / 轨道环 / 光带循环动效
- IntersectionObserver 滚动渐显

## 目录结构

```
.
├── index.html          # 主页面
└── videos/             # 视频作品（已压缩）
    └── covers/         # 视频封面帧
```

## 部署

本项目面向 GitHub Pages 静态托管。`videos/` 目录下为压缩后的视频素材，单个文件均小于 100MB。
